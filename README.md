# Курсовая работа
====
### Данный проект является курсовой работой по предмету "Технология разработки и защиты баз данных", написанной на третий год обучения, и представляет из себя интерфейс WindowsForms для расположенной на Microsoft SQL Server базе данных, которая содержит данные музыкального магазина.
  * Приложение написано на .NET Framework 4.8 в среде разработки Visual Studio 2024
>**Примечание**: проект более не является рабочим, ввиду отсутствия доступа к серверу с базой данных.
